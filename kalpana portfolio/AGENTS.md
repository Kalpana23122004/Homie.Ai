# AI Agent Instructions for this Workspace

## What this project is
- A simple static personal portfolio website.
- Main files:
  - `index.html`
  - `style.css`
  - `js/scrift.js`
- There is no build system, package manager, or backend in this workspace.

## How to contribute safely
- Keep solutions simple and use plain HTML, CSS, and JavaScript.
- Do not introduce frameworks, bundlers, or new toolchains unless the user explicitly requests them.
- Preserve the existing file structure and naming.
- Prefer browser-native features over external libraries.

## Coding conventions
- Match existing HTML structure and CSS selectors when updating styles.
- Use semantic HTML where possible, but avoid large rewrites without user approval.
- Keep JavaScript enhancements unobtrusive and limited to `js/scrift.js` unless the user asks for additional scripts.

## Project-specific guidance for Codex-style requests
- If asked to generate or improve UI features, stay within the current static site scope.
- Avoid adding unnecessary dependencies or modern build tooling.
- Focus on user-facing polish: responsive layout, accessibility, simple animations, and clear content structure.

## Previewing changes
- Changes can be reviewed directly by opening `index.html` in a browser.

## When in doubt
- Ask the user before making large structural changes.
- Prefer incremental updates over full rewrites.
